# Departure Mono Superbase (banner subset)

Web font used by Select 2026 promotional banners (`Select26Field`).

Source: Supabase’s Departure Mono Superbase derivative of Helena Zhang’s
[Departure Mono](https://departuremono.com), SIL OFL 1.1 (see `OFL.txt`).

Full font repo (OTF, sources, bolt glyph): select app
`apps/2026/src/fonts/departure-mono-superbase`.
