This reference documents every object and method available in v3 of the Supabase Swift library. The source is in the [supabase-swift repository](https://github.com/supabase/supabase-swift) on GitHub. With supabase-swift, you can query and update your Postgres data, listen to database changes, and invoke Deno Edge Functions. You can also sign users up and in, and upload, download, and delete large files.

v3 is in alpha. Its API can change before the stable release. To move an app from v2, read the [upgrade guide](/docs/reference/swift/v3/upgrade-guide).
