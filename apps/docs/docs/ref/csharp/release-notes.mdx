## 8.13.0 - 2026-11-19

**Features**

- Realtime: add presence join and leave handlers, `AddJoinHandler` and `AddLeaveHandler`, that receive the key and the presences involved ([#756](https://github.com/supabase/supabase-csharp/issues/756)).
- Realtime: `Subscribe()` connects the socket when the client has none, so `ConnectAsync()` is no longer required first ([#780](https://github.com/supabase/supabase-csharp/issues/780)).
- Realtime: reconnect as soon as the network comes back, controlled by `ClientOptions.MonitorsNetworkPath` ([#799](https://github.com/supabase/supabase-csharp/issues/799)).
- Realtime: log channel state changes to the supplied logger ([#797](https://github.com/supabase/supabase-csharp/issues/797)).
- Add `SupabaseOptions.LoggerFactory` to log request outcomes, retries, and background work such as token refresh and Realtime reconnects. Credentials, bodies, and query strings are never logged ([#766](https://github.com/supabase/supabase-csharp/issues/766)).
- Send the current trace context (`traceparent`, `tracestate`, `baggage`) with every Auth, Database, Storage, and Functions request. Turn it off with `SupabaseOptions.TracePropagation = TracePropagation.Disabled`. See [Client-side tracing](/docs/guides/observability/client-side-tracing?language=csharp) ([#762](https://github.com/supabase/supabase-csharp/issues/762)).
- Send Storage requests, uploads, and downloads through the client set in `SupabaseOptions.HttpClient` ([#758](https://github.com/supabase/supabase-csharp/issues/758)).
- Auth: disable session persistence with `SessionPersistence.Disabled` ([#761](https://github.com/supabase/supabase-csharp/issues/761)).
- Auth: manage OAuth clients as an admin: list, read, register, update, delete, and regenerate the secret ([#789](https://github.com/supabase/supabase-csharp/issues/789), [#791](https://github.com/supabase/supabase-csharp/issues/791), [#786](https://github.com/supabase/supabase-csharp/issues/786), [#792](https://github.com/supabase/supabase-csharp/issues/792), [#784](https://github.com/supabase/supabase-csharp/issues/784), [#788](https://github.com/supabase/supabase-csharp/issues/788)).
- Postgrest: bulk insert and upsert rows that carry different fields, and use column defaults for omitted fields ([#770](https://github.com/supabase/supabase-csharp/issues/770), [#774](https://github.com/supabase/supabase-csharp/issues/774)).
- Postgrest: cap how many rows an update or delete may affect with `MaxAffected` ([#771](https://github.com/supabase/supabase-csharp/issues/771)).
- Postgrest: read exactly one row with `SingleOrThrowAsync` ([#776](https://github.com/supabase/supabase-csharp/issues/776)).

**Fixes**

- Realtime: close a channel removed while it is still joining ([#754](https://github.com/supabase/supabase-csharp/issues/754)), wait `ReconnectAfterInterval` between reconnect attempts ([#783](https://github.com/supabase/supabase-csharp/issues/783)), send queued messages after a rejoin ([#755](https://github.com/supabase/supabase-csharp/issues/755)), and complete a push only on its own reply ([#781](https://github.com/supabase/supabase-csharp/issues/781)).
- Realtime: do not open the socket when `Disconnect()` runs during the token lookup ([#782](https://github.com/supabase/supabase-csharp/issues/782)), and ignore exceptions thrown by debug handlers ([#731](https://github.com/supabase/supabase-csharp/issues/731)).
- Storage: add `Bucket.FileSizeLimitInBytes` to read a numeric `file_size_limit` ([#801](https://github.com/supabase/supabase-csharp/issues/801)), and read `FileObjectV2.Size` as a `long` so objects over 2 GiB deserialize ([#804](https://github.com/supabase/supabase-csharp/issues/804)).

## 8.0.0 - 2026-09-03

Major release. All `Supabase.*` packages are versioned in lockstep. See the [migration guide](https://github.com/supabase/supabase-csharp/blob/master/docs/migrations/v8.0.0.md) for upgrade steps.

**Breaking changes**

- Migrate from `Newtonsoft.Json` to `System.Text.Json` across every package. Custom models with `[JsonProperty]` should move to `[JsonPropertyName]`; direct `JsonConvert` calls should move to `JsonSerializer` ([#360](https://github.com/supabase/supabase-csharp/issues/360)).
- Retarget every package to `netstandard2.1` (from `netstandard2.0`). .NET Framework and pre-`netstandard2.1` runtimes (Mono < 6.4, older Xamarin/Unity) are no longer supported — move to a `netstandard2.1`-capable target (.NET Core 3.0+/.NET 5+).
- Postgrest: parameterless `Table.Delete()` now returns `Task<ModeledResponse<T>>` (the deleted rows) instead of `Task` ([#342](https://github.com/supabase/supabase-csharp/issues/342)).
- Postgrest: `Single()` now throws a `PostgrestException` (status `406`) when more than one row matches, instead of returning `null` ([#346](https://github.com/supabase/supabase-csharp/issues/346)).
- Realtime: registering a `postgres_changes` listener after `Subscribe()` now throws a `RealtimeException` ([#385](https://github.com/supabase/supabase-csharp/issues/385)).
- Gotrue: stop sending the OAuth `state` parameter to `/authorize`; `SignInOptions.State` and `ProviderAuthState.State` are removed ([#388](https://github.com/supabase/supabase-csharp/issues/388)).
- Gotrue: rename `NetworkStatus.PingCheck` to `PingCheckAsync`.

**Features**

- Add the `Supabase.Extensions.DependencyInjection` package for DI registration. See [`AddSupabase()`](/docs/reference/csharp/initializing) ([#387](https://github.com/supabase/supabase-csharp/issues/387)).
- Add retry/backoff and injectable `HttpClient` support across all services ([#383](https://github.com/supabase/supabase-csharp/issues/383)).
- Support publishable and secret API keys ([#397](https://github.com/supabase/supabase-csharp/issues/397)).
- Gotrue: support async session persistence ([#399](https://github.com/supabase/supabase-csharp/issues/399)) and soft-delete on admin `DeleteUser` ([#402](https://github.com/supabase/supabase-csharp/issues/402)).
- Storage: expose the service error code ([#380](https://github.com/supabase/supabase-csharp/issues/380)).

**Fixes**

- Gotrue: a failed token refresh no longer signs the user out — only a server-reported invalid refresh token does ([#394](https://github.com/supabase/supabase-csharp/issues/394)).
- Postgrest: drop the `.` before nested `and`/`or` groups ([#389](https://github.com/supabase/supabase-csharp/issues/389)).
- Storage: percent-encode the object key in CDN purge URLs ([#384](https://github.com/supabase/supabase-csharp/issues/384)).
