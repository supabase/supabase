# Contributing to Supabase docs

Our docs help developers get started and keep succeeding with Supabase. We welcome contributions from everyone.

## How to contribute

1. Pick a [recommended issue](https://github.com/supabase/supabase/issues?q=is%3Aopen+is%3Aissue+label%3Adocumentation+label%3A%22help+wanted%22) or [open an issue](https://github.com/supabase/supabase/issues/new/choose) with your question or idea first. 
2. Draft your changes with our [AI agent skills for docs authoring](#write-with-an-ai-agent) and check them over as a human. 
3. Open the pull request, linking the issue.
