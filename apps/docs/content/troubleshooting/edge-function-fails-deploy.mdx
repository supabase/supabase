## Symptoms

The deployment returns `Function deploy failed due to an internal error` or `unexpected deploy status 500`.

## Confirm the cause

Deploy with the [Supabase CLI](/docs/guides/local-development) and the `--debug` flag to capture the bundle size and underlying error:

```bash
supabase functions deploy FUNCTION_NAME --project-ref PROJECT_REF --debug
```

If the output reports a script size above 20 MB, the locally bundled function exceeds the [Edge Function size limit](/docs/guides/functions/limits).

## Resolve

Reduce the bundle size or compare the [available bundle methods](/docs/reference/cli/supabase-functions-deploy):

- `--use-api`: Use Management API to bundle functions.
- Without `--use-api`: Bundle locally before uploading.

## Verify

Run the deployment again without `--debug` and confirm that it completes successfully.

## Escalate

If the debug output does not identify a code or bundle error, [open a support ticket](/dashboard/support/new) and include the command output.
