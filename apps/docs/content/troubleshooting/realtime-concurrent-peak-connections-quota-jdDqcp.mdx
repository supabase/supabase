The "Concurrent Peak Connections" quota refers to the maximum number of simultaneous connections to Supabase Realtime.

For example, if you have a chat application that uses Supabase Realtime and you have 100 users who are all connected and subscribed to the chat channel, then you would have 100 concurrent peak connections. Each client can connect to multiple [Realtime channels](/docs/guides/realtime/concepts#channels).

This quota applies to all Supabase projects, including self-hosted projects, but you can increase it depending on your use case. For hosted Supabase projects, select the plan that fits your Realtime usage and reach out if you need custom quotas. For self-hosted projects, set the `max_concurrent_users` field on the tenant record as described in the [self-hosted Realtime configuration guide](/docs/guides/self-hosting/realtime/config).

See [Realtime limits](/docs/guides/realtime/limits#limits-by-plan) for plan quotas.
