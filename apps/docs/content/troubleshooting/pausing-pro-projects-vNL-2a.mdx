Paid projects cannot be paused. Supabase grants two active Free Plan projects across organizations where you are an Owner or Administrator; paused projects do not count toward that limit. See [Free Plan billing](/docs/guides/platform/billing-on-supabase#free-plan).

To pause a paid project, [transfer it to a Free Plan organization](/docs/guides/platform/project-transfer) that remains within your free-project limit. Moving to a lower plan can remove paid features and briefly interrupt the project, so review the transfer constraints first.

Alternatively, you can download a [daily backup](/dashboard/project/_/database/backups/scheduled) of only your database for archiving. You can also manually download a .SQL file of your database and storage buckets by following this [guide](/docs/guides/platform/migrating-within-supabase/backup-restore).

You can also download your storage buckets with the [Supabase CLI:](/docs/guides/local-development/cli/getting-started?queryGroups=platform&platform=npx)

```bash
supabase login

# link to your project
supabase link --project-ref your-project-ref

# download one bucket into the current directory
supabase storage cp -r ss:///bucket . --experimental
```

Repeat the copy command for each bucket and verify the downloaded object count before pausing or transferring the project.
