Prefer the package's npm specifier instead of an esm.sh compatibility build. For Stripe:

```ts
import Stripe from 'npm:stripe@22'
```

If you must keep a legacy esm.sh import, pin the package version and add `?target=deno` to request a Deno-compatible build. New functions should use the npm specifier.
