Common questions about connection pool settings for the shared pooler (Supavisor) and the dedicated pooler (PgBouncer):

- How to tell which pooler you're using:
  The dedicated pooler connection string looks like: `postgres://postgres:[YOUR-PASSWORD]@db.xxxxxxxxxx.supabase.co:6543/postgres`

The shared pooler connection string looks like: `postgres://postgres.xxxxxxxxx:[YOUR-PASSWORD]@aws-0-us-west-1.pooler.supabase.com:6543/postgres`

The subdomain will vary depending on the region a project is deployed in. The project reference is to be included in the username following a `.`. If the username is `postgres` the username you use for the shared pooler is `postgres.[PROJECT_REF]`.

- How to update the size of the connection pool to the database:
  You can set the `Connection pool size` field in your [database settings](/dashboard/project/_/database/settings). Both poolers read this setting.

- How to change the client connection limit:
  The `Max client connections` field in your [database settings](/dashboard/project/_/database/settings) is fixed by your [compute size](/docs/guides/platform/compute-and-disk) and can't be changed directly. To raise it, upgrade your compute size.

- How to use `session` mode:
  Use the shared pooler connection string with port `5432` in it. The dedicated pooler runs in transaction mode only.
