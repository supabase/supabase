## Symptoms

Realtime connections return `TIMED_OUT` when using a recent `@supabase/supabase-js` version on Node.js versions earlier than 22.

## Confirm the cause

Record the Node.js and `@supabase/supabase-js` versions in the affected environment. If the same client connects on Node.js 22 or later, the transport compatibility is the likely cause. See [GitHub Discussion 37869](https://github.com/orgs/supabase/discussions/37869) for the underlying client change.

## Resolve

Choose one option:

1. Upgrade the runtime to Node.js 22 or later.
2. Explicitly configure a compatible WebSocket transport as described in [GitHub Discussion 37869](https://github.com/orgs/supabase/discussions/37869).

## Verify

Restart the application and confirm the channel reaches `SUBSCRIBED` without a `TIMED_OUT` status.

## Escalate

If the timeout persists on a supported Node.js version, capture the client logger output and corresponding [Realtime logs](/dashboard/project/_/logs/realtime-logs), then [open a support ticket](/dashboard/support/new).
