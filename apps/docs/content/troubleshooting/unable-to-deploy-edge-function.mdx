## Symptoms

`supabase functions deploy` fails before a new function version becomes active.

## Confirm the cause

1. **Check function syntax:** Run `deno check` on your function files locally
2. **Review dependencies:** Verify all imports are accessible and compatible with Deno
3. **Examine bundle size:** Large functions may fail to deploy

```bash
# Check for syntax errors
deno check ./supabase/functions/your-function/index.ts

# Deploy with verbose output
supabase functions deploy your-function --debug
```

## Resolve

- **Syntax errors:** TypeScript or JavaScript syntax issues in your function code
- **Invalid imports:** Importing modules that don't exist or aren't compatible with Deno
- **Large bundle size:** Locally bundled functions have a 20 MB limit, while server-side bundled functions have a 5 MB limit. See [Bundle size issues](./edge-function-bundle-size-issues) for details
- **Network issues:** Problems reaching the Supabase API during deployment

## Verify

Run `supabase functions deploy your-function` again and confirm the new version appears in the Supabase Dashboard.

## Escalate

Check your Supabase CLI version and compare it with the [installation guide](/docs/guides/local-development/cli/getting-started) before retrying:

```bash
supabase --version
```

If these steps don't resolve the issue, [open a support ticket](/dashboard/support/new) and include all output from the diagnostic commands.
