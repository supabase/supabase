## Symptoms

A query against a Wrappers foreign table returns `ERROR: HV000: guest fdw error: component verification failed`.

## Confirm the cause

Inspect the foreign server options and compare the configured package URL, version, and checksum with the values published for that wrapper in the [Wrappers catalog](https://fdw.dev/catalog/wasm/):

```sql
select srvname, unnest(srvoptions) as option
from pg_foreign_server
where srvname = 'example_server';
```

The mismatch is confirmed when at least one configured value differs. Wrappers blocks the Wasm module rather than executing an unverified component.

## Resolve

Update the foreign server through the [SQL Editor](/dashboard/project/_/sql/new), replacing every placeholder with the values for the same published package release:

```sql
ALTER SERVER example_server OPTIONS (
  SET fdw_package_url '[THE_CORRECT_URL]',
  SET fdw_package_version '[THE_CORRECT_VERSION]',
  SET fdw_package_checksum '[INTERNAL_ID]'
);
```

## Verify

Inspect the server options again:

```sql
select srvname, unnest(srvoptions) as option
from pg_foreign_server
where srvname = 'example_server';
```

Test the connection by querying your foreign table:

```sql
select * from example_table limit 1;
```

Confirm that the query completes without `HV000` and returns the expected remote data.

## Escalate

If the published URL, version, and checksum match but verification still fails, capture the extension version, wrapper name, server options with credentials removed, and Postgres log error. Report the mismatch to the wrapper maintainer or open a [support ticket](/dashboard/support/new).
