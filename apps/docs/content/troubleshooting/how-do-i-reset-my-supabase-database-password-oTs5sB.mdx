You can reset your database password from the [**Database > Settings**](/dashboard/project/_/database/settings) section of the Dashboard.

If you connect through the [shared pooler (Supavisor)](https://supabase.com/docs/guides/database/connecting-to-postgres#poolers), the first pooled connection after resetting an existing role's password (including `postgres`) may fail with an authentication error (`28P01`) even when the password is correct. This is expected. Retry with the new password and it should succeed.
