## Symptoms

The Dashboard shows `Failed to Fetch`, and an action such as a `PATCH` request does not complete.

![image](/docs/img/troubleshooting/7fe991ac-40ea-4628-a5e3-181d706225ea.png)

## Confirm the cause

Open the same page in a private window with extensions disabled. If the action succeeds there, enable extensions one at a time and reproduce the request. CORS-modifying, privacy, ad-blocking, and antivirus extensions can block or rewrite methods such as `PATCH` before the request reaches Supabase.

<img
  width="704"
  alt="168501713-5f020510-4555-4cc3-84de-582efc1c62de"
  src="https://github.com/supabase/supabase/assets/54564956/c61b9292-2954-4c68-8129-995941f36210"
/>

## Resolve

Disable the extension for `supabase.com`, or change its rules so it does not intercept Dashboard requests. If the failure also occurs with extensions disabled, inspect the browser console and network panel for DNS, TLS, proxy, or policy errors instead.

## Verify

Repeat the original Dashboard action and confirm that its request completes with the expected status. Re-enable unrelated extensions and verify that the problem does not return.

## Escalate

If a current supported browser reproduces the failure in a fresh profile on more than one network, open a [support ticket](/dashboard/support/new) with the project reference, timestamp, browser version, request method and path, and a sanitized network error. Do not include authorization headers or cookies.
