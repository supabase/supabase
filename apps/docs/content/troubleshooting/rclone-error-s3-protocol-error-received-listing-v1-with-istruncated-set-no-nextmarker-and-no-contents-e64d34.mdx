## Symptoms

`rclone lsf` returns `s3 protocol error: received listing v1 with IsTruncated set, no NextMarker and no Contents` while listing a Supabase bucket.

## Confirm the cause

This issue arises because `rclone` defaults to using S3 List API Version 1. This version may not correctly handle large, paginated bucket listings when interacting with Supabase Storage.

## Resolve

To resolve this, explicitly instruct `rclone` to use S3 List API Version 2. This can be done by adding the `--s3-list-version 2` flag to your `rclone lsf` command.

```bash
rclone lsf supabase:bucket-name --s3-list-version 2
```

## Verify

Run the command again and confirm that it lists every expected object without the protocol error.

## Escalate

If the error persists, capture the output from `rclone -vv` and include it in a [support ticket](/dashboard/support/new).
