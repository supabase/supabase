[VisuaLeaf](https://visualeaf.com/) is a desktop database client for Windows, macOS, and Linux. If you do not have it, download the free Community Edition from the [VisuaLeaf website](https://visualeaf.com/download).

<StepHikeCompact>

  <StepHikeCompact.Step step={1}>
    <StepHikeCompact.Details title="Create a new connection">
      In VisuaLeaf, click **New Connection**. Under **PostgreSQL-compatible**, select **Supabase**.
    </StepHikeCompact.Details>

    <StepHikeCompact.Code>
      ![The VisuaLeaf New Connection dialog with Supabase selected under PostgreSQL-compatible.](/docs/img/guides/database/connecting-to-postgres/visualeaf/new-connection.png)
    </StepHikeCompact.Code>

  </StepHikeCompact.Step>

  <StepHikeCompact.Step step={2}>
    <StepHikeCompact.Details title="Add your connection string">
      In the Supabase Dashboard, click [**Connect**](/dashboard/project/_?showConnect=true&method=session), choose **Session pooler**, and copy the connection string.

      Replace `[YOUR-PASSWORD]` with your database password. If you forgot it, reset it in [Database Settings](/dashboard/project/_/database/settings). If the password contains reserved URI characters such as `@`, `:`, `/`, `?`, or `#`, percent-encode them. For example, `@` becomes `%40`.

      In VisuaLeaf, paste the connection string into **Paste Connection URL** and click **Auto-Fill**. The host, port, database, and username fill in.

      <Admonition type="note">

        If you're in an [IPv6 environment](https://github.com/orgs/supabase/discussions/27034) or have the IPv4 add-on, you can use the direct connection string instead of the session pooler.

      </Admonition>

    </StepHikeCompact.Details>

    <StepHikeCompact.Code>
      ![The VisuaLeaf connection form filled in from a Supabase session pooler connection string.](/docs/img/guides/database/connecting-to-postgres/visualeaf/supabase-connection.png)
    </StepHikeCompact.Code>

  </StepHikeCompact.Step>

  <StepHikeCompact.Step step={3}>
    <StepHikeCompact.Details title="Verify the server certificate">
      Download your SSL certificate from [Database Settings](/dashboard/project/_/database/settings).

      In VisuaLeaf, expand **Advanced driver properties** and add the two properties shown. `sslmode=verify-full` encrypts the connection and checks that the server presents a certificate issued by Supabase. Without it, the Postgres driver uses `prefer` and can fall back to an unencrypted connection.
    </StepHikeCompact.Details>

    <StepHikeCompact.Code>
      ```txt
      sslmode      verify-full
      sslrootcert  /path/to/prod-ca-2021.crt
      ```
    </StepHikeCompact.Code>

  </StepHikeCompact.Step>

  <StepHikeCompact.Step step={4}>
    <StepHikeCompact.Details title="Test and connect">
      Click **Test Connection**, then **Save & Connect**. Your schemas and tables appear in the **Connections** panel. Open a table to browse its rows, or right-click the database to open a SQL editor.
    </StepHikeCompact.Details>

    <StepHikeCompact.Code>
      ![VisuaLeaf connected to a Supabase database, with the public schema expanded and a table open.](/docs/img/guides/database/connecting-to-postgres/visualeaf/connected-table.png)
    </StepHikeCompact.Code>

  </StepHikeCompact.Step>

</StepHikeCompact>
