## Partner Catalog: Build your landing page

Use this path for a Partner Catalog listing. The **Add integration** button on your listing links to a landing page on your site. You can link to your homepage or your docs. A Supabase-specific guide can help explain how the user configures their project to use Supabase and your APIs.

When it's complete, [share it with your partner manager](#publish).

## Integration

Use this path for an integration. You build the OAuth flow so users can connect, then call the Management API on their behalf.

### Build the OAuth flow

The OAuth flow is how a user lets your app act securely on their Supabase organization and projects. The user chooses which organization to connect and approves the scopes you request. Your app then gets an access token limited to those scopes, so it never sees the user's password. The user can revoke access at any time. Complete the following in order.

<ContentListings id="build-integration-oauth-build" />

### Build the integration

Call the Management API with the access token to read and change your users' organizations and projects. With it, your app can list a user's organizations and projects, read project settings and API keys, run database migrations, deploy Edge Functions and manage their secrets, and create projects. What your app can do depends on the scopes the user approved.

## Publish

After you test the flow against a project you own, ask your partner manager to list you on the [Partner Catalog](/partners/catalog) or the [Integrations page](/docs/guides/integrations).
