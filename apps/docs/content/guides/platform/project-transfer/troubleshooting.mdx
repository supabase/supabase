description: 'Find the cause and the fix for each message that blocks a Supabase project transfer, in the Dashboard or the Management API, and for a missing transfer button.'

Find out why a project transfer is blocked, and what to do about it. For the steps of a transfer, see [Transfer a project](/docs/guides/platform/project-transfer).

The _source organization_ is the organization the project belongs to before the transfer. The _target organization_ is the organization you move the project to.

When a check fails, the Supabase Dashboard shows a **Project cannot be transferred** box with one or more messages. The Management API's preview endpoint returns the same messages in its `errors` list. When a check fails, the transfer endpoint returns HTTP `400` with the messages after the text `Transfer is not possible, due to the following reasons:`. Two cases differ: a transfer to the project's current organization returns `400` with only its own message, and the endpoint returns `503` while transfers are paused.

The following tables list each message with its cause and fix. Some long messages are shortened to their first sentences, so match on the start of the message.

## Role and membership messages

The following table lists the messages about your role in the two organizations:

| Message                                                                                      | Cause                                                                                                                                                                                                         | Fix                                                                                                                                                                    |
| -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| You must be an owner of the project to transfer a project.                                   | You aren't an Owner of the source organization.                                                                                                                                                               | Ask an Owner to transfer the project or to make you an Owner.                                                                                                          |
| You must be a member of the target organization to transfer a project.                       | The account you're signed in with isn't a member of the target organization. An SSO account counts as a separate account.                                                                                     | Ask for an invitation for this account.                                                                                                                                |
| You must have organization permissions within the target organization to transfer a project. | You have the **No-access** role or only project-scoped roles in the target organization, or your access token doesn't include the target organization or lacks **Organization Members** with **Read** access. | Ask an Owner for a role for the whole organization, or create a token with the access listed in [Prerequisites](/docs/guides/platform/project-transfer#prerequisites). |

## The transfer button is missing or disabled

The following list covers each case where you can't start or confirm a transfer in the Dashboard:

- **The Transfer project section is missing.** You're viewing a branch. Open the main project instead.
- **Transfer project is disabled.** The tooltip gives the reason:
  - `You need additional permissions to transfer this project`: only an Owner of the source organization can transfer.
  - `Project transfers are temporarily disabled, please try again later.`: transfers are temporarily paused.
- **The dialog shows `You do not have any organizations you can transfer your project to.`** Your account is a member of no other organization. Create an organization, or ask for an invitation to one.
- **Transfer Project in the dialog is disabled.** No target organization is selected, the checks are still running, or a check is failing. Read the **Project cannot be transferred** box.

## The transfer fails after you confirm

If you see a message that starts with `Failed to transfer project:` after you confirm, compare the rest of the message with the messages in the [Role and membership messages](#role-and-membership-messages), [Billing and limit messages](#billing-and-limit-messages), and [Project feature messages](#project-feature-messages) sections. If the text matches none of them, check which organization owns the project before you try again.
