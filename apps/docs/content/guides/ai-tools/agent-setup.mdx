When you finish this page, your AI coding agent can run Supabase commands, use the Supabase MCP server, and load Supabase Agent Skills.

To have your agent do the setup, paste this prompt into it:

```text
Set up Supabase in this project by following
https://supabase.com/docs/guides/ai-tools/agent-setup
```

If you are an AI coding agent, run the commands on this page yourself. Ask the user only when a step needs their decision or their sign-in.

## Prerequisites

You need the following before you start:

- A project directory to set up.
- [Node.js](https://nodejs.org) 20 or later, for the `npm` and `npx` commands.

## Set up Supabase for your agent

Run these steps in order.

1. Open a terminal in your project directory.
2. Install the Supabase CLI. Skip this step if `package.json` already lists `supabase`, or if the `supabase` command already works. In a Node.js project, install the CLI as a dev dependency so the version is pinned per project:

   ```bash
   npm install supabase --save-dev
   ```

   In any other project, install the CLI with Homebrew, Scoop, or a Linux package. See [Install the Supabase CLI](/docs/guides/local-development/cli/getting-started#installing-the-supabase-cli). If your CLI is installed that way, run `supabase` in place of `npx supabase` in the commands that follow.

3. Install the Supabase Plugin. It bundles the MCP server and Agent Skills:

   ```bash
   npx plugins add supabase-community/supabase-plugin
   ```

   The command installs the plugin into every agent it detects, and it asks you to confirm first. If you are an AI coding agent, get the user's approval before you skip the confirmation with `--yes`. To install the plugin for one agent by hand, see [manual installation](/docs/guides/ai-tools/plugins#manual-installation).

4. Check whether your project has a `supabase` directory with a `config.jsonc`, `config.json`, or `config.toml` file. If it doesn't, initialize Supabase:

   ```bash
   npx supabase init
   ```

## Verify

Check that the CLI and the MCP server work.

1. Print the CLI version:

   ```bash
   npx supabase --version
   ```

   The command prints a version number.

2. Ask your agent: "List my Supabase projects. Use MCP tools." Your MCP client redirects you to sign in to Supabase in a browser window. Choose the organization that contains the project you want to work with. Your agent then lists your projects. Depending on the client, you might need to restart it before it detects the MCP server.
