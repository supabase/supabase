To enable Kakao Auth for your project, you need to set up a Kakao OAuth application and add the application credentials to your Supabase Dashboard.

## Overview

Kakao OAuth consists of six broad steps:

1. Create and configure your app in the [Kakao Developers Portal](https://developers.kakao.com/changeLang?lang=en).
2. Obtain a **REST API key**. This serves as the `client_id`.
3. Obtain a **Kakao Login Client Secret code**. This serves as the `client_secret`.
4. Configure additional settings in the Kakao Developers Portal.
5. Add your client ID and client secret to your [Supabase project](/dashboard).
6. Add the sign-in code to your client app.

## Access your Kakao Developer account

1. Go to the [Kakao Developers Portal](https://developers.kakao.com/changeLang?lang=en).
2. At the top right, click **Login** to sign in.

![Kakao Developers Portal home page with the Login button at the top right of the navigation bar](/docs/img/guides/auth-kakao/kakao-developers-page.png)

## Create and configure your app

1. Go to **App**.
2. At the top, click **Create app**.
3. Fill out your app information:
   - App icon
   - App name
   - Company name
   - Category
   - App primary domain
4. At the bottom right, click **Save**.

## Obtain a REST API key

The REST API key serves as the `client_id` when you make API calls to authenticate the user.

1. Go to **App** and click your app.
2. Go to **App Settings** > **App** > **Platform Key**.
3. In the **Platform Key** section, copy the **REST API key**.

## Find your callback URL

<$Partial path="social_provider_setup.mdx" variables={{ "provider": "Kakao" }} />

To add the callback URL on Kakao:

1. Go to **App Settings** > **App** > **Platform Key**.
2. Click the REST API key you want to use.
3. On the edit page, enter your callback URL in the **Kakao Login Redirect URI** field.
4. At the bottom right, click **Save**.

## Obtain a client secret

The client secret serves as the `client_secret` for your Supabase project.

1. Go to **App Settings** > **App** > **Platform Key**.
2. Click the REST API key you want to use.
3. Copy the **Kakao Login Client Secret code**.
4. Activate **Kakao Login Client Secret**.

## Additional configurations on Kakao Developers Portal

1. Go to **Product Settings** > **Kakao Login** > **General**.
2. In the **Usage settings** section, set **State** to "ON" to enable Kakao Login.
3. Go to **Product Settings** > **Kakao Login** > **Consent Items**.
4. Set the following scopes under **Consent Items**:
   - `account_email` (optional)
   - `profile_image`
   - `profile_nickname`

If you don't need an email address, or `account_email` isn't available for your app, omit `account_email`.

![Consent Items page under Product Settings > Kakao Login, with profile_nickname and profile_image set to Required consent and account_email set to Optional consent](/docs/img/guides/auth-kakao/kakao-developers-consent-items-set.png)

<Admonition type="note">

The `account_email` consent item is only available to Biz apps in the Kakao Developers Portal. To convert your app to a Biz app, go to **App Settings** > **App** > **General** and complete the **Business Information** section.

</Admonition>

## Using Kakao SDK for JavaScript

The [Kakao SDK for JavaScript](https://developers.kakao.com/docs/latest/en/kakaologin/js) is an official Kakao SDK for authenticating Kakao users on websites.

Exchange the [authorization code returned by the Kakao API](https://developers.kakao.com/docs/latest/en/kakaologin/rest-api#request-code) for an [ID Token](https://developers.kakao.com/docs/latest/en/kakaologin/common#login-with-oidc). For example, the following code gets an ID Token:

```js
const requestUrl = new URL(request.url)
const code = requestUrl.searchParams.get('code')

if (code) {
  const res = await fetch('https://kauth.kakao.com/oauth/token', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/x-www-form-urlencoded;charset=utf-8',
    },
    body: new URLSearchParams({
      grant_type: 'authorization_code',
      client_id: '<CLIENT_ID>',
      redirect_uri: '<url>/api/auth/kakao/oidc',
      code,
      client_secret: '<CLIENT_SECRET>',
    }),
  })

  const { id_token } = await res.json()
}
```

Use the ID Token to sign in:

```js
const res = await supabase.auth.signInWithIdToken({
  provider: 'kakao',
  token: id_token,
})
```

### Configuration

1. On the Kakao Developers Portal, set **State** to "ON" under [OpenID Connect Activation](https://developers.kakao.com/docs/latest/en/kakaologin/prerequisite#kakao-login-oidc).
2. Add `openid` to [scope](https://developers.kakao.com/docs/latest/en/kakaologin/prerequisite#scope-setting) along with the scope values you want to request consent for.
