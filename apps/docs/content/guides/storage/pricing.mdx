title: 'Pricing'
---

You are charged for the total size of all assets in your buckets. If storage usage is higher than expected or you see a storage size quota error, see [Storage size quota errors](/kb/troubleshooting/storage-unexpectedly-high-usage-or-exceed_storage_size_quota-errors).

<$Partial path="billing/pricing/pricing_storage_size.mdx" />

For a detailed explanation of how charges are calculated, refer to [Manage Storage size usage](/docs/guides/platform/manage-your-usage/storage-size).

<Admonition type="caution">

If you use [Storage Image Transformations](/docs/guides/storage/serving/image-transformations), additional charges apply.

</Admonition>
