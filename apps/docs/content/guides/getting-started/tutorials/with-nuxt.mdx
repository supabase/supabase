## Building the app

Build the Nuxt 4 and TypeScript.

### Initialize a Nuxt 4 app

Use [`npm create nuxt`](https://nuxt.com/docs/4.x/getting-started/installation) to create an app called `nuxt-user-management`:

```bash
npm create nuxt@latest nuxt-user-management

cd nuxt-user-management
```

Then install [Nuxt Supabase](https://supabase.nuxtjs.org/), which provides the Supabase client and composables used in this tutorial.

```bash
npm install -D @nuxtjs/supabase
```

Save the environment variables in `.env`. Use the URL and publishable key that you copied [earlier](#get-api-details).

<$CodeTabs>

```text name=.env
NUXT_PUBLIC_SUPABASE_URL="YOUR_SUPABASE_URL"
NUXT_PUBLIC_SUPABASE_KEY="YOUR_SUPABASE_PUBLISHABLE_KEY"
```

</$CodeTabs>

These variables are exposed in the browser. That is safe because this app uses the publishable key and [Row Level Security](/docs/guides/auth#row-level-security) protects database access.
Nuxt Supabase reads the variables automatically, so you do not need to initialize a client yourself.

### App styling (optional)

Optionally, update `app/assets/main.css` to style the app.
You can find the full contents of this file [in the example repository](https://github.com/supabase-community/nuxt3-quickstarter/blob/main/assets/main.css).

<$CodeTabs>

```typescript name=nuxt.config.ts
export default defineNuxtConfig({
  modules: ['@nuxtjs/supabase'],
  css: ['~/assets/main.css'],
})
```

</$CodeTabs>

Nuxt auto-imports `defineNuxtConfig`, Vue APIs, and components from `app/components`, so no import statements are needed in the examples below.

### Set up the Auth component

Set up a Vue component to manage login and sign-up. This tutorial uses Magic Links, so users can sign in with their email without a password.

<$CodeTabs>

```vue name=app/components/Auth.vue
<script setup lang="ts">
const supabase = useSupabaseClient()

const loading = ref(false)
const email = ref('')

async function handleLogin() {
  try {
    loading.value = true
    const { error } = await supabase.auth.signInWithOtp({ email: email.value })
    if (error) throw error
    alert('Check your email for the login link.')
  } catch (error) {
    alert(error instanceof Error ? error.message : 'Unable to send magic link.')
  } finally {
    loading.value = false
  }
}
</script>

<template>
  <form class="form-widget" @submit.prevent="handleLogin">
    <h1 class="header">Supabase + Nuxt 4</h1>
    <p class="description">Sign in with a magic link sent to your email.</p>
    <input v-model="email" class="inputField" type="email" placeholder="Your email" required />
    <input
      type="submit"
      class="button block"
      :value="loading ? 'Loading' : 'Send magic link'"
      :disabled="loading"
    />
  </form>
</template>

<style scoped>
.form-widget {
  max-width: 28rem;
  margin: 0 auto;
}

.inputField,
.button {
  width: 100%;
  margin-top: 0.75rem;
}
</style>
```

</$CodeTabs>

### User state

To use the signed-in user's information, use the [`useSupabaseUser`](https://supabase.nuxtjs.org/composables/usesupabaseuser) composable provided by Nuxt Supabase.

### Account component

After a user signs in, let them edit their profile details, upload a profile photo, and manage their account. Create `app/components/Account.vue`:

<$CodeTabs>

```vue name=app/components/Account.vue
<script setup lang="ts">
const supabase = useSupabaseClient()
const user = useSupabaseUser()

const loading = ref(true)
const username = ref('')
const website = ref('')
const avatarPath = ref('')

if (user.value) {
  const { data } = await supabase
    .from('profiles')
    .select('username, website, avatar_url')
    .eq('id', user.value.id)
    .single()

  if (data) {
    username.value = data.username ?? ''
    website.value = data.website ?? ''
    avatarPath.value = data.avatar_url ?? ''
  }
}

loading.value = false

async function updateProfile() {
  if (!user.value) return

  try {
    loading.value = true
    const { error } = await supabase.from('profiles').upsert({
      id: user.value.id,
      username: username.value,
      website: website.value,
      avatar_url: avatarPath.value,
      updated_at: new Date().toISOString(),
    })

    if (error) throw error
    alert('Changes saved.')
  } catch (error) {
    alert(error instanceof Error ? error.message : 'Unable to save profile.')
  } finally {
    loading.value = false
  }
}

async function signOut() {
  try {
    loading.value = true
    const { error } = await supabase.auth.signOut()
    if (error) throw error
  } catch (error) {
    alert(error instanceof Error ? error.message : 'Unable to sign out.')
  } finally {
    loading.value = false
  }
}
</script>

<template>
  <form class="form-widget" @submit.prevent="updateProfile">
    <div>
      <label for="email">Email</label>
      <input id="email" type="text" :value="user?.email" disabled />
    </div>
    <div>
      <label for="username">Username</label>
      <input id="username" v-model="username" type="text" />
    </div>
    <div>
      <label for="website">Website</label>
      <input id="website" v-model="website" type="url" />
    </div>
    <Avatar v-model:path="avatarPath" />
    <input
      type="submit"
      class="button primary block"
      :value="loading ? 'Loading ...' : 'Update profile'"
      :disabled="loading"
    />
    <button type="button" class="button block" @click="signOut" :disabled="loading">
      Sign out
    </button>
  </form>
</template>

<style scoped>
.form-widget {
  max-width: 28rem;
  margin: 0 auto;
}

.form-widget > div,
.form-widget > .button,
.form-widget > input {
  margin-top: 1rem;
}

input,
.button {
  width: 100%;
}
</style>
```

</$CodeTabs>

## Profile photos

Supabase provides [Storage](/docs/guides/storage) for managing large files such as photos and videos.

### Create an upload widget

Create `app/components/Avatar.vue`:

<$CodeTabs>

```vue name=app/components/Avatar.vue
<script setup lang="ts">
const props = defineProps<{ path: string }>()
const emit = defineEmits<{ 'update:path': [path: string] }>()
const supabase = useSupabaseClient()

const uploading = ref(false)
const src = ref('')
let objectUrl: string | undefined

async function downloadImage() {
  if (!props.path) {
    src.value = ''
    return
  }

  try {
    const { data, error } = await supabase.storage.from('avatars').download(props.path)
    if (error) throw error

    if (objectUrl) URL.revokeObjectURL(objectUrl)
    objectUrl = URL.createObjectURL(data)
    src.value = objectUrl
  } catch (error) {
    console.error('Error downloading image:', error)
  }
}

async function uploadAvatar(event: Event) {
  const input = event.target as HTMLInputElement
  const file = input.files?.[0]

  if (!file) return

  try {
    uploading.value = true
    const fileExt = file.name.split('.').pop() ?? 'jpg'
    const filePath = `${crypto.randomUUID()}.${fileExt}`
    const { error } = await supabase.storage.from('avatars').upload(filePath, file)

    if (error) throw error
    emit('update:path', filePath)
  } catch (error) {
    alert(error instanceof Error ? error.message : 'Unable to upload image.')
  } finally {
    uploading.value = false
    input.value = ''
  }
}

onMounted(downloadImage)
watch(() => props.path, downloadImage)
onBeforeUnmount(() => {
  if (objectUrl) URL.revokeObjectURL(objectUrl)
})
</script>

<template>
  <div class="avatar-picker">
    <img v-if="src" :src="src" alt="Avatar" class="avatar" />
    <div v-else class="avatar no-image" aria-hidden="true" />
    <label class="button primary" for="avatar-upload">
      {{ uploading ? 'Uploading ...' : 'Upload avatar' }}
    </label>
    <input
      id="avatar-upload"
      class="file-input"
      type="file"
      accept="image/*"
      :disabled="uploading"
      @change="uploadAvatar"
    />
  </div>
</template>

<style scoped>
.avatar-picker {
  display: grid;
  gap: 0.75rem;
  justify-items: start;
  margin-top: 1rem;
}

.avatar {
  width: 10rem;
  height: 10rem;
  object-fit: cover;
  border-radius: 9999px;
}

.no-image {
  background: var(--color-surface-200, #e5e7eb);
}

.file-input {
  position: absolute;
  width: 1px;
  height: 1px;
  overflow: hidden;
  clip: rect(0 0 0 0);
  white-space: nowrap;
}
</style>
```

</$CodeTabs>

With all the components in place, update `app/app.vue`:

```vue name=app/app.vue
<script setup lang="ts">

</script>

<template>
  <div class="container">

<style scoped>

  padding: 3rem 0 6rem;
}
</style>
```

</$CodeTabs>

Once that's done, run this in a terminal window:

```bash
npm run dev
```

Open [localhost:3000](http://localhost:3000) in your browser to see the completed app.

## Add a server route

The app now authenticates the user on the client. For protected API endpoints or server-rendered data, add a server route that verifies the session.

[`@supabase/server`](https://supabase.github.io/server/) handles this flow through a single middleware: it validates the JWT locally, attaches an RLS-scoped Supabase client and the user's claims to the request, and rejects unauthenticated requests with a 401 before your handler runs.

```bash
npm install @supabase/server
```

<$CodeTabs>

```typescript name=server/api/profile.get.ts
import { withSupabase } from '@supabase/server/adapters/h3'
import { defineEventHandler, createError } from 'h3'

export default defineEventHandler({
  middleware: [withSupabase({ auth: 'user' })],
  handler: async (event) => {
    const { supabase, userClaims } = event.context.supabaseContext

    const { data, error } = await supabase
      .from('profiles')
      .select('username, website, avatar_url')
      .eq('id', userClaims.id)
      .single()

    if (error) {
      throw createError({ statusCode: 500, statusMessage: error.message })
    }

    return data
  },
})
```

</$CodeTabs>

For an unauthenticated route, pass `auth: 'none'`. For app-wide authentication, register `withSupabase({ auth: 'user' })` as Nuxt server middleware at `server/middleware/supabase.ts`. See the [h3/Nuxt adapter docs](https://supabase.github.io/server/adapters/h3) for typing, route overrides, and the full API.
