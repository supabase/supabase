## 3. Create a Capacitor app

Create a React app with the [Vite](https://vitejs.dev/guide/) TypeScript template, then add [Capacitor](https://capacitorjs.com/) so you can run the same UI in the browser and on Android devices.

```bash
npm create vite@latest my-app -- --template react-ts
cd my-app
npm install
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "My App" com.example.myapp --web-dir dist
npx cap add android
```

## 5. Install the Supabase client library

The fastest way to get started is to use the `@supabase/supabase-js` client library, which runs inside the Capacitor WebView and in the browser during development. Install it together with `@capacitor/preferences` so Auth sessions can persist on native platforms.

```bash
npm install @supabase/supabase-js @capacitor/preferences
```

<Admonition type="note">

[`@capgo/capacitor-supabase`](https://github.com/Cap-go/capacitor-supabase) wraps the native Supabase SDKs on Android and iOS. It is a good fit when you add sign-in, because it stores sessions in the native layer and exposes JWTs to your web code. [`@capgo/capacitor-social-login`](https://github.com/Cap-go/capacitor-social-login) helps when you need provider sign-in (Google, Apple, and others) and want to pass tokens to [Supabase Auth](/docs/guides/auth). This quickstart only queries Postgres with `supabase-js`, which matches how most Capacitor teams use Realtime, Storage, and Edge Functions without extra native bridges.

</Admonition>

## 7. Initialize the Supabase client

Create a helper file at `src/lib/supabase.ts` to initialize the Supabase client using the environment variables.

On native platforms, use `@capacitor/preferences` as the Auth storage adapter. In the browser, use `localStorage`.

```ts name=src/lib/supabase.ts
import { Capacitor } from '@capacitor/core'
import { Preferences } from '@capacitor/preferences'
import { createClient } from '@supabase/supabase-js'

const supabaseUrl = import.meta.env.VITE_SUPABASE_URL
const supabasePublishableKey = import.meta.env.VITE_SUPABASE_PUBLISHABLE_KEY

const capacitorAuthStorage = {
  getItem: (key: string) => Preferences.get({ key }).then(({ value }) => value ?? null),
  setItem: (key: string, value: string) => Preferences.set({ key, value }),
  removeItem: (key: string) => Preferences.remove({ key }),
}

export const supabase = createClient(supabaseUrl, supabasePublishableKey, {
  auth: {
    storage: Capacitor.isNativePlatform() ? capacitorAuthStorage : localStorage,
    autoRefreshToken: true,
    persistSession: true,
    detectSessionInUrl: false,
  },
})
```

## 8. Query data from the app

Replace the contents of `src/App.tsx` with the following code to fetch and display the instruments from your database.

Use `useEffect` to fetch the data when the component mounts and render the query result in the page.

```tsx name=src/App.tsx
import { useEffect, useState } from 'react'

import { supabase } from './lib/supabase'

type Instrument = {
  id: number
  name: string
}

export default function App() {
  const [instruments, setInstruments] = useState<Instrument[]>([])
  const [error, setError] = useState<string | null>(null)

  useEffect(() => {
    getInstruments()
  }, [])

  async function getInstruments() {
    const { data, error } = await supabase.from('instruments').select()

    if (error) {
      setError(error.message)
      return
    }

    setInstruments(data ?? [])
  }

  if (error) {
    return <p>Error loading instruments: {error}</p>
  }

  return (
    <ul>
      {instruments.map((instrument) => (
        <li key={instrument.id}>{instrument.name}</li>
      ))}
    </ul>
  )
}
```

## 9. Start the app

Run the Vite dev server and open http://localhost:5173 in a browser to confirm the instruments list loads.

```bash
npm run dev
```

To run on an Android device or emulator, build the web assets, copy them into the native project, and start the Android run target.

```bash
npm run build
npx cap sync
npx cap run android
```
