## 3. Set up a virtual environment

Create a new directory for your Django app and set up a virtual environment.

```bash
mkdir my-app && cd my-app
python3 -m venv venv
source venv/bin/activate
```

## 4. Install Supabase's Agent Skills (optional)

Supabase's [Agent Skills](/docs/guides/ai-tools/ai-skills) is a curated set of instructions that give your AI agent procedural knowledge about working with Supabase.

Install them so your AI coding agent can produce more accurate, reliable code using current Supabase patterns, such as authentication, server-side rendering, and database migrations, rather than relying solely on training data.

To install, run the following command in the root of your project:

```bash
npx skills add supabase/agent-skills
```

## 5. Install Django and the Supabase client library

Install Django for the web framework and `supabase-py` which provides a convenient interface for working with Supabase from a Python app.

```bash
pip install django supabase
```

## 6. Create a Django project and app

Use `django-admin` to scaffold a new project, then create an app to hold your views.

```bash
django-admin startproject myproject .
python manage.py startapp instruments
```

## 7. Create environment variables file

Create a `.env` file in your project root and populate it with your Supabase connection variables that you can get from the helper below, or [from the project **Connect** panel](/dashboard/project/_?showConnect=true&connectTab=frameworks&framework=django):

## 8. Query data from the app

Install the `python-dotenv` package to load environment variables:

```bash
pip install python-dotenv
```

Update `instruments/views.py` to fetch data from your `instruments` table using the Supabase client.

```python name=instruments/views.py
import os
from django.http import JsonResponse
from supabase import create_client, Client
from dotenv import load_dotenv

load_dotenv()

supabase: Client = create_client(
    os.environ.get("SUPABASE_URL"),
    os.environ.get("SUPABASE_PUBLISHABLE_KEY")
)

def index(request):
    response = supabase.table('instruments').select("*").execute()
    return JsonResponse(response.data, safe=False)
```

## 9. Configure URL routing

Create `instruments/urls.py` to define the app URL pattern:

```python name=instruments/urls.py
from django.urls import path
from . import views

urlpatterns = [
    path('', views.index, name='index'),
]
```

Update `myproject/urls.py` to include the app URLs:

```python name=myproject/urls.py
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', include('instruments.urls')),
]
```

## 10. Start the app

Run the Django development server, and go to http://localhost:8000 in your browser. You should see the list of instruments as JSON.

```bash
python manage.py runserver
```
