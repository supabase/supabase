Performance monitor reads project data and reports findings from these checks: long-running and blocked sessions, query execution-time regressions, and Performance Advisor warnings and errors.

Use the [canonical checks](/docs/guides/observability/detecting#performance) for queries, thresholds, prerequisites, and interpretation. It records **finding**, **clear**, or **unable to assess** for each check. Missing history or failed access never becomes a healthy result. New findings and changed assessment failures are reported; unchanged repeats and clear runs stay quiet.
