Capacity monitor reads project data and reports findings from these checks: database and table sizes, connection snapshots, request growth, and resource forecasts supported by saved history and confirmed limits.

Use the [canonical checks](/docs/guides/observability/detecting#usage) for queries, thresholds, prerequisites, and interpretation. It records **finding**, **clear**, or **unable to assess** for each check. Missing history or failed access never becomes a healthy result. New findings and changed assessment failures are reported; unchanged repeats and clear runs stay quiet.
