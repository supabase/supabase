Generalist reads project data and reports findings from these checks: the same health, security, performance, and capacity checks as the specialist monitors, in one daily run.

Use the [canonical detection checks](/docs/guides/observability/detecting) for queries, thresholds, prerequisites, and interpretation. Generalist checks every complete hour in the preceding day for server-error signals. Its database checks are snapshots at run time, and query regressions compare daily intervals.

It records **finding**, **clear**, or **unable to assess** for each check. Missing history or failed access never becomes a healthy result. New findings and changed assessment failures are reported; unchanged repeats and clear runs stay quiet.
