Hire an agent to run recurring checks on your Supabase project. Each agent combines a prompt and a schedule. It reads project data and reports findings without changing your project.

## Choose an agent [#choose-a-routine]

Use Generalist for one daily pass, or a specialist for a particular job or cadence.

<ContentListings id="telemetry-hire-agent" />

## Set up your agent [#run-the-routine]

1. Connect [Supabase MCP](/docs/guides/ai-tools/mcp) with `project_ref` and `read_only=true`.
2. Copy the agent's prompt into your harness. Allow it to fetch the linked [detection checks](/docs/guides/observability/detecting), and set any threshold overrides for your workload.
3. Configure the harness to save and reload measurements and previous alert outcomes between runs, outside the project database. Comparisons need saved history; forecasts also need a confirmed resource limit. Without those inputs, the agent reports **unable to assess**.
4. Run manually first. Confirm that it can read the intended project and return useful results. Review any missing inputs before scheduling.
5. Set the agent's schedule and timezone, prevent overlapping runs, and choose where reports go. Reports stay in the harness unless you authorize an external destination or ticket creation.

## What to expect [#outcomes-and-notifications]

Each check records **finding**, **clear**, or **unable to assess**. Clear runs and unchanged repeats stay quiet. New findings or changed assessment failures produce a report with evidence and a next step. Failed access or missing history never counts as a healthy result.
