## Read project data [#metrics-api]

Logs record events, database statistics describe live or cumulative activity, and advisors return configuration findings. Reports visualize project signals; the Metrics API exports Prometheus-compatible database metrics.

<ContentListings id="telemetry-access-what" />

## From evidence to action

Observe the relevant data, detect a signal, and use its time window, error code, or affected object to diagnose the cause. After an authorized fix, rerun the check. Automate checks only after their results and thresholds are useful for your project.
