Source schema and table names cannot contain `"` or `;`. If either name starts or ends with `_`, Pipelines uses `_SSTT_<schema>_<table>` instead, preserving the original underscores. `SS` and `TT` are the two-digit lengths of the schema and table names. For this format, both names must contain only ASCII letters, digits, and underscores. For example, `public._orders` becomes `_0607_public__orders`, or `_0607_PUBLIC__ORDERS` in Snowflake. Check the generated destination name before writing queries.
