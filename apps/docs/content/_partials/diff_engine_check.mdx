`pg-delta` is the default diff engine. Your project uses the legacy `migra` engine only if your config file sets `experimental.pgdelta.enabled` to `false`, or `SUPABASE_EXPERIMENTAL_PGDELTA_ENABLED=false` is set in your shell or a project `.env` file. A single diff command also uses `migra` when you pass `--use-migra`. See [Diff engines](/docs/guides/local-development/diff-engines) for how the two differ and how to switch.
