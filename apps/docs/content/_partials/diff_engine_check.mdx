`pg-delta` is the default diff engine. Your project uses the legacy `migra` engine only if `config.toml` contains an `[experimental.pgdelta]` section with `enabled = false`, or `SUPABASE_EXPERIMENTAL_PGDELTA_ENABLED=false` is set in your shell or a project `.env` file. See [Diff engines](/docs/guides/local-development/diff-engines) for how the two differ and how to switch.
