The CLI uses the `pg-delta` diff engine unless `config.toml` opts out. If it contains an `[experimental.pgdelta]` section with `enabled = false`, your project uses the legacy `migra` engine. If the section is missing, or `enabled` is `true` or omitted, your project uses `pg-delta`. See [Diff engines](/docs/guides/local-development/diff-engines) for how the two differ and how to roll back.
