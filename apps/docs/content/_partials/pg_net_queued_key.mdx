`pg_net` writes the decrypted key to `net.http_request_queue` until it sends the request. While the request waits, any role that can log in to your database can read the key. For more information, see [Database roles can read request headers queued by `pg_net`](/docs/guides/troubleshooting/database-roles-can-read-request-headers-queued-by-pg_net-ad6357).
