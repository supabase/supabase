<Admonition type="note">

These steps use `sh run.sh`, a convenience wrapper around `docker compose` included in the `docker/` directory. Its `config add` / `config remove` commands manage the `COMPOSE_FILE` variable in your `.env`, and `docker compose` automatically layers those override files on top of `docker-compose.yml`. See [Managing the stack](/docs/guides/self-hosting/docker#managing-the-stack) for the full command reference.

</Admonition>
