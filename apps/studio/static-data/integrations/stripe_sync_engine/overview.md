[Stripe](https://stripe.com/) is an API driven payment processing and subscription management platform.

The Stripe Sync Engine will sync data from your Stripe account including 18 core resources into Postgres tables in your Supabase account. For a Stripe hosted integration to sync 48 different tables into your Supabase Postgres account in real time, check out [Stripe Data Pipeline Real-time sync to Postgres](https://dashboard.stripe.com/data-management/pipeline?destination=postgres_supabase)
