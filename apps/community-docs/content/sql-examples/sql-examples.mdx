## Getting started

{/* community-docs: manual body from `https://raw.githubusercontent.com/supabase-community/sql-examples/master/README.md` (see `getting-started-content-sources.json`) */}

This project is a **curated, open source** list of Supabase SQL you can copy into the SQL editor, with tested scripts. See the [live demo (database.dev)](https://database.dev/) and the repo’s **Features** and **About** sections for context.

**Stack:** Nuxt, Vite, and WindiCSS (see upstream README for badges and screenshots).

### Local development

**Prerequisites:** [Yarn](https://yarnpkg.com/) (for example `npm install --global yarn`).

1. Clone this repository: `git clone https://github.com/supabase-community/sql-examples.git`
2. Install dependencies: `yarn install`
3. Run the dev server: `yarn dev`

> Some links in the upstream README still use the older **supabase-sql** naming; the current Utilities listing points at [`sql-examples`](https://github.com/supabase-community/sql-examples).
