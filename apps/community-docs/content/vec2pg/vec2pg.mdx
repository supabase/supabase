## Installation

`vec2pg` is a simple package [available on PYPI](https://pypi.org/project/vec2pg/)

Requirements:

- Python >= 3.8

### From PYPI

Use your preferred package manager to add the package to your local enviroment.

Using pip
```sh
pip install vec2pg
```

Using poetry
```sh
poetry add vec2pg
```
