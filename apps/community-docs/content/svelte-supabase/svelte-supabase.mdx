## Getting started

{/* community-docs: manual body from `https://raw.githubusercontent.com/supabase-community/svelte-supabase/master/README.md` (see `getting-started-content-sources.json`) */}

This is an **experimental** preset that wires Supabase into a [SvelteKit](https://kit.svelte.dev) project.

### Usage

Start from a fresh SvelteKit app (see current SvelteKit docs for `npm create svelte@latest` or the template your team uses). In the project directory, run:

```sh
npx apply supabase-community/svelte-supabase
```

Then install dependencies (`npm install`, `yarn install`, or `pnpm install`) and add your Supabase URL and anon key to `.env` from the [Supabase dashboard](https://supabase.com/dashboard) → **Settings** → **API**.

Questions and issues are tracked on the [upstream template repository](https://github.com/joshnuss/svelte-supabase) linked from the community fork.
