## Getting started

{/* community-docs: manual body from `https://raw.githubusercontent.com/supabase-community/svelte-kanban/main/README.md` (see `getting-started-content-sources.json`) */}

[Trello](https://trello.com)-style Kanban demo backed by Supabase.

**Live demo:** [supabase-kanban.vercel.app](https://supabase-kanban.vercel.app/)

### Setup locally

1. Clone: `git clone https://github.com/supabase-community/svelte-kanban.git` and install with `pnpm install` (or `npm install` / `yarn`).
2. Create a Supabase project and run the SQL in [`setup.sql`](https://github.com/supabase-community/svelte-kanban/blob/main/setup.sql) in the SQL editor.
3. Copy `.env.example` to `.env` and set your Supabase URL and anon key.
4. Start the app: `pnpm dev` (or `npm run dev`).

### Building

```bash
npm run build
npm run preview
```

See the repository README for adapter and deployment notes.
