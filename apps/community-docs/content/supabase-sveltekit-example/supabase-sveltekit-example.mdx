## Getting started

Example [SvelteKit](https://kit.svelte.dev) app with Supabase and Gitpod.

### Gitpod

Open in Gitpod: [gitpod.io/#https://github.com/supabase-community/supabase-sveltekit-example](https://gitpod.io/#https://github.com/supabase-community/supabase-sveltekit-example)

### Running locally

Copy environment variables from `.env.example`:

```bash
cp .env.example .env
```

Fill in `SUPABASE_URL` and keys from the [Supabase dashboard](https://supabase.com/dashboard) → **Settings** → **API**.

### Developing

```bash
npm install
npm run dev
# or: npm run dev -- --open
```

### Building

`npm run build` uses the SvelteKit adapter configured in the project. See [SvelteKit adapters](https://kit.svelte.dev/docs/adapter-auto) if you change deployment targets.
