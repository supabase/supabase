Passwordless sign-in lets users log in without a password. They use a passkey on their device, a magic link sent to their email, or a one-time password (OTP) sent by email or SMS.

## Supabase Auth

[Supabase Auth](/docs/guides/auth) is an auth service built by Supabase.

Supabase Auth is the best choice if you want quick setup, many popular sign-in options ([password](/docs/guides/auth/passwords), [magic link](/docs/guides/auth/auth-email-passwordless#with-magic-link), [one-time password (OTP)](/docs/guides/auth/auth-email-passwordless#with-otp), [social sign-in](/docs/guides/auth/social-sign-in), and [single sign-on (SSO)](/docs/guides/auth/enterprise-sso)), and enterprise-grade security built on Postgres' Row Level Security.

Supabase Auth is also a good choice if your project already uses Supabase and needs passwordless sign-in, or if you're starting a new project that also needs the [Data API](/docs/guides/api), [Storage](/docs/guides/storage), [Realtime](/docs/guides/realtime), or [Edge Functions](/docs/guides/functions).

## Clerk

Clerk is a user management platform for web and mobile apps. Its prebuilt sign-in components handle email codes, email links, and SMS codes.

Choose Clerk if you want hosted sign-in UI and session management for web or mobile apps.

## Auth0

Auth0, owned by Okta, is an identity platform for consumer and enterprise apps. Email OTP and SMS OTP work on both Universal Login and Classic Login. Magic links and passkeys are also available, with some limits.

Choose Auth0 if you already use it, or if you need an established platform with enterprise connections.

## Amazon Cognito

Amazon Cognito is AWS's identity service. Its user pools support passkeys, email OTP, and SMS OTP. You can use them in Managed Login or in a custom UI built with the AWS SDK.

Choose Cognito if your infrastructure already runs on AWS.

## WorkOS

WorkOS is built for enterprise B2B software. Its AuthKit product includes Magic Auth, which emails a six-digit code that expires after 10 minutes, and passkeys. Single sign-on and directory sync are useful if your customers are enterprises.

Choose WorkOS if you want a hosted sign-in page with Magic Auth and passkeys, and you don't need passkeys in your own custom UI.

## Firebase Auth

Firebase Auth is Google's identity service within the Firebase platform. It supports email links and phone OTPs.

Choose Firebase Auth if your app already runs on Firebase or Google Cloud and email links or phone OTPs meet your needs.

## Microsoft Entra External ID

Microsoft Entra External ID is Microsoft's customer identity service for consumer and business apps. It supports passkeys as a first or second factor, email one-time passcodes for local accounts, and SMS codes as a second factor on a paid add-on.

Choose Entra External ID if your customers or organization already use Microsoft identity.

## Better Auth

Better Auth is an open source authentication library for TypeScript apps. It runs inside your own app and offers passwordless sign-in through plugins for magic links, email and phone OTP, and passkeys.

Choose Better Auth if you want passwordless sign-in to run as a library inside your TypeScript app, instead of as a separate service.

You can use Better Auth with a Supabase Postgres database. See [Set up Better Auth with Supabase Declarative Schema](/kb/guides/setup-better-auth-with-declarative-schema).
