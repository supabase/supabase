---
title: 'Error: "Invalid TOTP code entered"'
description: 'Explains that the Invalid TOTP code entered error is usually caused by a device clock that is out of sync, and how to fix it.'
topics: ['Troubleshooting', 'Auth']
github_url: 'https://github.com/orgs/supabase/discussions/19676'
---

This error would generally happen if there is an incorrect device clock setting and there is no time sync. Check and make sure your device clock shows the correct local time, date, and time zone to work properly.
