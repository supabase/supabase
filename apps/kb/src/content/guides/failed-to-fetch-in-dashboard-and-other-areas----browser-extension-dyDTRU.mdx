Although Failed to Fetch can occur for a variety of reasons a common one in the dashboard or when using update code is related to a browser extension.

![Chrome Web Store listing for the Allow CORS extension](/kb/img/troubleshooting/7fe991ac-40ea-4628-a5e3-181d706225ea.png)

[Allow CORS browser extension](https://chrome.google.com/webstore/detail/allow-cors-access-control/lhobafahddgcelffkeicbaginigeejlf)
