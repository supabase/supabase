---
title: 'I am not receiving password reset emails for Supabase dashboard'
description: 'Explains why Supabase dashboard password reset emails may not arrive when the account was created via GitHub login, and what to do next.'
topics: ['Troubleshooting', 'Supabase Platform']
github_url: 'https://github.com/orgs/supabase/discussions/14043'
---

Most likely, you signed up on Supabase using a GitHub account. Try the GitHub login method to see if you can log in. If you still cannot log in, write to support@supabase.com using your email with a screenshot of the error from the dashboard.
