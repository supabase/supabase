---
title: 'How do I reset my Supabase database password?'
description: 'Explains how to reset a database password from the Dashboard and why Supavisor connections may briefly fail with a 28P01 error right after.'
topics: ['Troubleshooting', 'Database']
github_url: 'https://github.com/orgs/supabase/discussions/20929'
---

You can reset your database password from the [**Database > Settings**](/dashboard/project/_/database/settings) section of the Dashboard.

If connections through the [Shared Pooler (Supavisor)](/docs/guides/database/connecting-to-postgres) start failing right after you reset it — including for the built-in `postgres` role — this `28P01` error is expected, and retrying with the new password usually succeeds. See [Supavisor error: "password authentication failed" after rotating database password](/kb/guides/supavisor-error-password-authentication-failed-after-password-rotation) for more detail.
