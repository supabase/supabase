This error usually occurs when the database reaches the maximum number of connections allowed based on the compute add-on.

To overcome this, the connections need to be optimized as mentioned [here](/docs/guides/platform/performance#optimizing-the-number-of-connections)

Additionally, you can try using the [connection pool](/docs/guides/database/connecting-to-postgres/pooling-and-limits#how-connection-pooling-works) to help solve this issue.

If you're already using connection pooling and still hitting the maximum connections, then it is suggested to upgrade your [compute add-on](/docs/guides/platform/compute-and-disk) that allows more connections
