---
title: Can I use Better Auth as an authentication provider with Supabase?
topics: ['Auth']
lastEdited: 2026-11-10
---

Yes. You can use Better Auth as an authentication provider with Supabase.

If you have an application using Better Auth and want to store its users and sessions in Supabase, follow [Set up Better Auth with Supabase Declarative Schema](/kb/guides/setup-better-auth-with-declarative-schema). Every Supabase project is a full Postgres database, so Better Auth connects to it directly.

If you are building a new application, consider building it all on Supabase, which includes [Auth](/docs/guides/auth), a [full Postgres database](/docs/guides/database/overview), a [Data API (REST and GraphQL)](/docs/guides/api), [Storage](/docs/guides/storage), [Realtime](/docs/guides/realtime), [Edge Functions](/docs/guides/functions), and more.
