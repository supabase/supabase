---
title: Do I have to move my users to Supabase Auth to use Supabase?
---

No. Supabase provides first-class support for several [third-party authenctication providers](https://supabase.com/docs/guides/auth/third-party/overview), so your existing users can stay where they are.

These providers (Clerk, Firebase Auth, WorkOS, etc.) can then access Supabase features (like the [Data API (REST and GraphQL)](/docs/guides/database/overview), [Storage](/docs/guides/storage), [Realtime](/docs/guides/realtime) and [Functions](/docs/guides/functions)) from your existing apps.

For more details how this affects pricing, refer to [Manage Monthly Active Third-Party Users usage](https://supabase.com/docs/guides/platform/manage-your-usage/monthly-active-users-third-party).
