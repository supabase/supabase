---
title: Can I use Amazon Cognito as an authentication provider with Supabase?
topics: ['Auth']
lastEdited: 2026-10-23
---

Yes. You can use Amazon Cognito as an authentication provider with Supabase.

If you have an application using Amazon Cognito and want access to the Supabase Platform, use the [Amazon Cognito integration with Supabase](/docs/guides/auth/third-party/aws-cognito).

If you are building an application using Amazon Cognito and need a [standalone Postgres database](/docs/guides/database/overview), you can also use Supabase. In this case, you would set up your own authentication and authorization flows using any provider.

If you are building a new application, consider building it all on Supabase, which includes [Auth](/docs/guides/auth), a [full Postgres database](/docs/guides/database/overview), a [Data API (REST and GraphQL)](/docs/guides/api), [Storage](/docs/guides/storage), [Realtime](/docs/guides/realtime), [Edge Functions](/docs/guides/functions), and more.
