---
title: Can I use Amazon Cognito as an authentication provider with Supabase?
topics: ['Auth']
---

Yes. You can use Amazon Cognito as an authentication provider alongside [Supabase Auth](/docs/guides/auth), or standalone, with your Supabase project.

If you already have a production app using Amazon Cognito and want access to the rest of the Supabase Platform, use the [Amazon Cognito integration with Supabase](/docs/guides/auth/third-party/aws-cognito).

For more details on how this affects pricing, see [Manage Monthly Active Third-Party Users usage](/docs/guides/platform/manage-your-usage/monthly-active-users-third-party).
