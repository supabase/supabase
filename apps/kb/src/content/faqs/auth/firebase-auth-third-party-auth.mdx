---
title: Can I use Firebase Auth as an authentication provider with Supabase?
topics: ['Auth']
---

Yes. You can use Firebase Auth as an authentication provider alongside [Supabase Auth](/docs/guides/auth), or standalone, with your Supabase project.

If you already have a production app using Firebase Auth and want access to the rest of the Supabase Platform, use the [Firebase Auth integration with Supabase](/docs/guides/auth/third-party/firebase-auth).

If you want to move your users from Firebase Auth to Supabase Auth instead, refer to the [Firebase Auth migration guide](/kb/guides/migrate-from-firebase-auth).

For more details on how this affects pricing, see [Manage Monthly Active Third-Party Users usage](/docs/guides/platform/manage-your-usage/monthly-active-users-third-party).
