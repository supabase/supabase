---
title: Can I use Clerk as an authentication provider with Supabase?
topics: ['Auth']
---

Yes. You can use Clerk as an authentication provider alongside [Supabase Auth](/docs/guides/auth), or standalone, with your Supabase project.

If you already have a production app using Clerk and want access to the rest of the Supabase Platform, use the [Clerk integration with Supabase](/docs/guides/auth/third-party/clerk).

For more details on how this affects pricing, see [Manage Monthly Active Third-Party Users usage](/docs/guides/platform/manage-your-usage/monthly-active-users-third-party).
