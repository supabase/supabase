---
title: Can I use OpenID Connect identity providers in Supabase projects?
---

Yes. Any identity provider that supports OpenID Connect (OIDC) can be used as a third-party authentication provider alongside Supabase Auth, or standalone, with your Supabase project.

For more details, refer to [Custom OIDC providers](https://supabase.com/docs/guides/auth/third-party/custom-oidc).
