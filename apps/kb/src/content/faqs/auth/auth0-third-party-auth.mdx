---
title: Can I use Auth0 as an authentication provider with Supabase?
topics: ['Auth']
---

Yes. You can use Auth0 as an authentication provider with Supabase.

If you have an application using Auth0 and want access to the Supabase Platform, use the [Auth0 integration with Supabase](/docs/guides/auth/third-party/auth0).

If you have an application using Auth0 and want a new authentication provider, consider to [migrating from Auth0 to Supabase](/kb/guides/migrate-from-auth0).

If you are building an application using Auth0 and need a [standalone PostgreSQL database](/docs/guides/database/overview), you can also use Supabase. In this case, you would set up your own authentication and authorization flows using any provider.

If you are building a new application, consider building it all on Supabase, which includes [Auth](/docs/guides/auth), a [full PostgreSQL database](/docs/guides/database/overview), a [Data API (REST and GraphQL)](/docs/guides/api), [Storage](/docs/guides/storage), [Realtime](/docs/guides/realtime), [Edge Functions](/docs/guides/functions), and more.
