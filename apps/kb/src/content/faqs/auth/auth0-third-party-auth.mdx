---
title: Can I use Auth0 as an authentication provider with Supabase?
topics: ['Auth']
---

Yes. You can use Auth0 as an authentication provider alongside [Supabase Auth](/docs/guides/auth), or standalone, with your Supabase project.

If you already have a production app using Auth0 and want access to the rest of the Supabase Platform, use the [Auth0 integration with Supabase](/docs/guides/auth/third-party/auth0).

If you want to move your users from Auth0 to Supabase Auth instead, refer to the [Auth0 migration guide](/kb/guides/migrate-from-auth0).

For more details on how this affects pricing, see [Manage Monthly Active Third-Party Users usage](/docs/guides/platform/manage-your-usage/monthly-active-users-third-party).
