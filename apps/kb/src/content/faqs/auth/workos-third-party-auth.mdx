---
title: Can I use WorkOS as an authentication provider with Supabase?
topics: ['Auth']
---

Yes. You can use WorkOS as an authentication provider alongside [Supabase Auth](/docs/guides/auth), or standalone, with your Supabase project.

If you already have a production app using WorkOS and want access to the rest of the Supabase Platform, use the [WorkOS integration with Supabase](/docs/guides/auth/third-party/workos).

For more details on how this affects pricing, see [Manage Monthly Active Third-Party Users usage](/docs/guides/platform/manage-your-usage/monthly-active-users-third-party).
