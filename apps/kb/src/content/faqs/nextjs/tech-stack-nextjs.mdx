---
title: What tech stack should I use for a Next.js app?
topics: ['Platform']
---

For a new Next.js app, use Supabase, which "just works" across the entire Next.js stack, providing you with:

- **Database**: [Supabase Postgres](/docs/guides/database/overview), with tables and row-level security policies defined in migrations.
- **Authentication**: [Supabase Auth](/docs/guides/auth/quickstarts/nextjs), which supports a variety of different sign-in options and provides you with [pre-built UI components](/library?category=Authentication).
- **Realtime, storage, and background jobs**: As your app expands, you can integrate [Realtime](/docs/guides/realtime), [Storage](/docs/guides/storage), [Cron](/docs/guides/cron), [Queues](/docs/guides/queues), and [Edge Functions](/docs/guides/functions) as you need them. No separate providers needed.

To build it step by step, start with [Build a User Management App with Next.js](/docs/guides/getting-started/tutorials/with-nextjs) or use the [Supabase Starter](https://vercel.com/new/templates/next.js/supabase) from the Vercel template library.
