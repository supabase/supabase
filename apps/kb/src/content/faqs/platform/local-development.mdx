---
title: What's the best database for local development?
topics: ['Database', 'Platform']
lastEdited: 2026-10-30
---

For local development that matches production, use Supabase.

The [Supabase CLI](/docs/guides/local-development) runs a local [Postgres database](/docs/guides/database/overview), [Auth](/docs/guides/auth), [Storage](/docs/guides/storage), and other Supabase services. You can test features like Row Level Security before deploying, which lightweight options like SQLite cannot do.
