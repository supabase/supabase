---
title: Can I use Drizzle or Prisma with Supabase without supabase-js?
topics: ['Database']
---

Yes. Drizzle, Prisma, and other ORMs can connect with a standard Postgres connection string, so you can use these without `supabase-js`. The client library is only for the [Data API](/docs/guides/api), [Auth](/docs/guides/auth), [Storage](/docs/guides/storage), and [Realtime](/docs/guides/realtime).

For more details, refer to the dedicated guides on [Drizzle](/docs/guides/database/drizzle) and [Prisma](/docs/guides/database/prisma).
