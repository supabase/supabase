---
title: Can I use Supabase as the database for a mobile app?
topics: ['Database', 'Auth']
---

Yes. Supabase has client libraries for [Flutter](/docs/guides/getting-started/tutorials/with-flutter), [Swift](/docs/guides/getting-started/tutorials/with-swift), [Kotlin](/docs/guides/getting-started/tutorials/with-kotlin), as well as detailed tutorials on [Ionic Vue](/docs/guides/getting-started/tutorials/with-ionic-vue), [Ionic React](/docs/guides/getting-started/tutorials/with-ionic-react), and [Expo React Native](/docs/guides/getting-started/quickstarts/expo-react-native).

The app talks to Postgres through the [Data API](/docs/guides/api) using a Supabase client library, and [Row Level Security](/docs/guides/database/postgres/row-level-security) decides what each signed-in user can see and change. For anything secret, such as payment calls, use [Supabase Edge Functions](/docs/guides/functions). For live features like chat, use [Supabase Realtime](/docs/guides/realtime) to stream database changes to the app.
