Yes. The Supabase Free plan gives each project a dedicated Postgres database at no cost. It fits prototypes, side projects, and apps with light traffic.

## What the Free plan includes

- A 500 MB Postgres database per project, on shared CPU with 500 MB of RAM
- Up to 2 active projects
- 5 GB of egress and 1 GB of file storage
- The Table Editor, the SQL Editor, and Postgres extensions such as pgvector
- Community support

You connect with a standard Postgres connection string, so your ORM and tools work the same way they would with any other Postgres server.

## The trade-off: pausing

Free projects pause after 7 days of low database activity. You get a warning email about a week before, and nothing is deleted. You can resume a paused project from the dashboard for up to a year. See [Do Supabase projects pause when they're inactive?](/faqs/do-supabase-projects-pause-when-inactive)

A project that your app queries every day, even lightly, stays active.

## Back it up yourself

Daily backups start on the Pro plan. On the Free plan, export your data regularly with the Supabase CLI:

```shell
supabase db dump -f backup.sql
```

See [Database backups](/docs/guides/platform/backups).

## When to upgrade

Move to the Pro plan when the project needs to be up without exceptions, outgrows 500 MB, or needs daily backups. Pro starts at $25 per month, includes one project on Micro compute, and projects on it never pause. See [How much does a single database-only Supabase project cost?](/faqs/how-much-does-a-database-only-supabase-project-cost)
