---
title: "How do I put my app's database online so other people can use my app?"
description: 'Move the data from a local file or local server into a hosted Postgres database, and point the deployed app at it through an environment variable.'
date: '2026-09-28'
---

Move your data into a hosted database that your deployed app can reach over the internet, then give the app its connection string through an environment variable. A database file or server on your own computer can't be reached by an app running somewhere else.

## 1. Create a hosted database

Create a Supabase project. Each project is a dedicated Postgres database with a public connection endpoint, protected by a password and SSL.

## 2. Pick the right connection string

Open **Connect** in the dashboard and choose based on where your app will run:

- **Serverless or edge functions:** shared pooler, transaction mode, on port `6543`.
- **A server or container that stays running:** the direct connection, or the shared pooler in session mode if the host only supports IPv4.

See [Connect to your database](/docs/guides/database/connecting-to-postgres).

## 3. Configure the app

1. Read the connection string from an environment variable, such as `DATABASE_URL`.
2. Set that variable on your hosting platform. Never commit it to the repository.
3. Switch your ORM or driver to Postgres if it used another database locally.

## 4. Create the schema and move the data

1. Run your migrations against the new database from your machine or CI.
2. Import existing data. For small tables, use CSV import in the dashboard. For more, use `COPY` or `pgloader`. See [Import data into Supabase](/docs/guides/database/import-data).

Coming from a local SQLite file? See [How do I move an app from SQLite to hosted Postgres for production?](/faqs/how-do-i-move-an-app-from-sqlite-to-hosted-postgres)

## 5. Lock it down

- Keep SSL required and the password out of client code.
- If browsers or mobile apps will query tables directly, enable Row Level Security first. See [Row Level Security](/docs/guides/database/postgres/row-level-security).
- If only your servers connect, you can limit which IP ranges may reach the database. See [Network restrictions](/docs/guides/platform/network-restrictions).

## Keep it running

On the Free plan, projects pause after 7 days of low activity. If people depend on the app, use a paid plan, where projects never pause.
