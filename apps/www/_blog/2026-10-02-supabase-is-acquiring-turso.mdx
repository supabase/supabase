AI is enabling builders to create an immense amount of software. Today, agents are spinning up millions of databases to power the prototypes, explorations, dashboards, and apps they're building. This new pattern, at this massive scale, requires an evolution in database infrastructure. Turso is joining Supabase to build this evolution.
For existing users, nothing changes. Supabase will continue building around Postgres, while Turso will continue its work on SQLite. And together, we’re creating something new that will bring the Supabase experience to every agent.

## Databases for agents

Supabase is already launching nearly 1 million databases per week. As agents build more software, database demand will outpace the world’s current capacity to support them. So we need infrastructure that can scale to meet this growth and is also fit for how we build with agents.

Agents should be able to create a database instantly. For smaller workloads, that shouldn’t require provisioning a dedicated machine every time. Databases should be cheap to create, isolated, and available on demand.
SQLite is very good at this; Postgres is what you want as your application scales.

## Turso

Turso has built an architecture for exactly this problem. They rebuilt SQLite in Rust and created a cloud platform where a single server can manage millions of databases, loading them when needed and evicting them when they’re not.

Their architecture enables the provisioning of on-demand per-agent databases both in the public Cloud and BYOC, for customers like Superhuman, Sauna.ai, CTO.new, and Mastra.
We have a shared understanding of how infrastructure will evolve to support the future of agentic AI. The Turso platform continues operations, with a clear graduation path into the rest of the Supabase ecosystem.

## Open source

Turso and Supabase have a lot in common: open source, developer experience, and a willingness to tackle hard infrastructure problems.
We’re excited to welcome Glauber Costa and Pekka Enberg to Supabase with the rest of the Turso team. Glauber will lead Agentic Services.

Our mission is to store the world’s data, and agents are going to create a lot more of it. This gets us closer to that goal.
