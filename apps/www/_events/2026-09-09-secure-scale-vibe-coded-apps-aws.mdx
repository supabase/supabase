AI coding tools help you build fast, but successful deployment takes the right foundation.

Supabase is the easy-to-use, open source managed Postgres with integrated backend services. It is an all-in-one suite with Database, Auth, Storage, Edge Functions, Realtime, and Vector search. AI agents connect through the Supabase MCP server and Agent Skills, all on AWS.

In this session, Nick Littman, Customer Solutions Architect at Supabase, and Mrinali Umashankar, Solutions Architect II at AWS, show you how to take an AI-built application and make it launch-ready.

## Key takeaways

- Protect AI-built applications with a built-in security advisor, row-level security, and platform security controls.
- Locate slow queries, apply the right indexes, and prepare for production load.
- Use test environments and a tested rollback path.
- Track your applications across native dashboards, logs, and OpenTelemetry (OTEL) integrations.
