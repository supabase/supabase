# Supabase Brand Guidelines

> Official Supabase logos and colors, as SVG and PNG files for light and dark backgrounds.

## Which file to use

- Choose the file for the background where the logo appears, not for your browser or editor theme.
- If a request asks for "the Supabase logo", use the wordmark with black lettering on a light background.
- On a dark background, use the wordmark with white lettering.
- In small spaces or next to other brand icons, use the green icon.
- If you can print only one color, use the black or white one-color wordmark.
- All files have a transparent background.
- There is no file with the lettering alone. Every wordmark file includes the symbol.

## Name

Write Supabase as one word, with a capital S. Do not write SupaBase or Supa Base.

## Usage

Use the Supabase logos only to refer to Supabase. Do not change the files or the logo colors.
