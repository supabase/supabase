---
title: Tracing
description: Composable primitives for distributed-trace views built on the shared design system
---

```tsx
import { Trace } from 'ui-patterns/Trace'
```

`Trace.Root` indexes a list of OpenTelemetry-style spans and shares the result with the parts inside it. `Trace.Waterfall` is the layout container and measures its width so time can be mapped to pixels. `Trace.Ruler` draws the time axis and `Trace.Grid` draws the vertical gridlines below it, and `Trace.Cursor` draws the live cursor. The waterfall has two columns: the tree (`treeWidth`) and the timeline. The children of `Trace.Ruler` render at the right end of the ruler's tree cell, next to the "Span" label.

## Waterfall and Ruler

The ruler adapts its ticks to the visible range. While a trace is live (any span has no end), `Trace.Cursor` also draws a line at `nowMs` from the top of the ruler to the bottom of the waterfall, with a dot on the ruler's bottom edge. Pass `nowMs` on the trace to pin it, and `minRangeMs` to keep a minimum visible duration while live.

## Rows and bars

`Trace.Rows` is a virtualized, scrollable list with one row per visible span. Its children are the row template and render once per row. `Trace.Cell` is the tree column: indent by depth, an expand and collapse toggle, the span name, and a spinner while the span is running. `Trace.Lane` is the timeline column, a positioned container for the primitives below.

Five primitives go inside a `Trace.Lane`. `Trace.Bar` draws the span from its start to its end, tinted by status. A running span extends to `nowMs`. `Trace.Timing` shows the span's duration just after the bar, or inside the bar's end when there is no room after it. `Trace.Markers` places a marker at each of the span's event timestamps. `Trace.CollapsedChildren` draws a tick at each direct child's midpoint when a span is collapsed. `Trace.Slowest` badges the longest finished span. Compose them in this order so markers and the badge draw over the bar:

```tsx
<Trace.Lane>
  <Trace.Bar />
  <Trace.Timing />
  <Trace.CollapsedChildren />
  <Trace.Markers />
  <Trace.Slowest />
</Trace.Lane>
```

Rows follow the tree pattern. Use the arrow keys to move between rows, Right and Left to expand and collapse (Left on a collapsed row moves to its parent), and Enter or Space to select. Read the selection and collapse state with `useView()`.
