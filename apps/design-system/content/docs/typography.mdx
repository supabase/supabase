Use shared typography styles to keep text consistent across apps. You can find the
heading, text, and link utilities in [`typography.css`](https://github.com/supabase/supabase/blob/master/packages/config/typography.css).

## Primary text

Use `text-primary` for readable text in Supabase green.

`text-primary` meets WCAG AA for normal text on app surfaces: darkened in light mode,
bright in dark mode. Focus rings and selected controls derive their brighter fill from
the same primary hue. See [Primary and brand colors](../docs/color-usage#primary-and-brand-colors) for when
to use each green.

## Inline code

Apps that import `config/inline-code.css` get shared styles for inline `<code>`, including
a border, background, and default foreground color. Code inherits the surrounding font weight
and line height, with text 1.5px smaller and a minimum of `0.75rem` (normally 11.5px). For example,
16px prose gives you 14.5px code, while 13px prose gives you 11.5px code.

Long identifiers stay intact when they fit on the next line, but can break to avoid overflow.
Tailwind utilities can override the defaults. A size class on `<code>` sets its size directly;
put the class on a parent to keep the 1.5px reduction:

```tsx
<span className="text-sm">
  <code>project_id</code>
</span>
```

Code blocks and syntax-highlighting containers keep their own styles. For other custom
displays, such as a command strip, add `data-code-style="plain"` to the `<code>` element
or a parent. This removes all shared inline-code styles from that element and its descendants,
so the display can control its own appearance.
