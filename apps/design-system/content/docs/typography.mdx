Some reusable patterns work better as CSS variables, or “shorthands”, than as components. Typography is one of these cases, since its usage and context vary widely.

The shorthands below are composed of core [Tailwind utility classes](../docs/tailwind-classes). You can view the full list of shorthands in [`typography.scss`](https://github.com/supabase/supabase/blob/master/apps/studio/styles/typography.scss).

## Shorthands

| Value                | Usage                                                                      |
| -------------------- | -------------------------------------------------------------------------- |
| `text-code-inline`   | Apply to a `code` element for inline code or similar custom inline content |
| `text-brand`         | Supabase green for large or non-essential branded text                     |
| `text-brand-display` | Brighter Supabase green for large, expressive display text only            |

`text-brand` is independent from `bg-brand-default`, `border-brand-default`, and other non-text brand utilities. In light mode it favours readability without becoming as dark as the previous accessible green. It has 3.83:1 contrast against white, so it is suitable for large text and non-essential accents but does not meet the 4.5:1 WCAG AA requirement for normal text.

Use `text-brand-display` only where the brand treatment is expressive rather than the sole means of conveying information. Its light-mode value has 2.40:1 contrast against white.
