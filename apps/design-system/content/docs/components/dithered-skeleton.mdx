`DitheredSkeleton` is a drop-in alternative to [Skeleton](/docs/components/skeleton). Instead of a flat pulse, it renders drifting noise through an ordered-dither pattern, with a shine band whose edge ripples as it sweeps across.

<ComponentPreview name="dithered-skeleton-demo" peekCode wide />

## Usage

```tsx
import { DitheredSkeleton } from 'ui'

;<DitheredSkeleton className="h-4 w-[200px]" />
```

Size and shape it with `className`, the same way you would a `Skeleton`.

## Behavior

- **Continuous across a page:** The texture and shine are mapped to page coordinates, so neighboring skeletons read as one surface catching the same light.
- **Cheap at scale:** Every instance shares a single animation loop capped at 30 frames per second, and instances outside the viewport stop rendering.
- **Reduced motion:** When the user prefers reduced motion, a static textured frame is shown instead.
- **Theme-aware:** The dither color follows `text-foreground-lighter` over `bg-muted`, in both light and dark themes.

### Fine grain

For a finer, more tactile texture, set `pixelSize` below `1` to dither at device resolution, and add `grain` (`0`–`1`) for flickering film-like noise. On a 1x display, sub-pixel sizes fall back to one physical pixel.

## Lite variant

`DitheredSkeletonLite` keeps the dithered look but does no per-frame JavaScript, so its cost stays the same regardless of skeleton size, count, or device. Use it as the default for loading states. Keep `DitheredSkeleton` for small, prominent placements where the full procedural effect matters.

<ComponentPreview name="dithered-skeleton-lite-demo" peekCode wide />

### Usage

```tsx
import { DitheredSkeletonLite } from 'ui'

;<DitheredSkeletonLite className="h-4 w-[200px]" />
```

It accepts the same `className`, `pixelSize`, and `speed` props as `DitheredSkeleton`.

### How it works

- **Baked texture:** The noise and ordered dither are rendered once per cell size into small, seamless mask tiles. Every instance on the page shares the same tiles.
- **Compositor-driven shine:** The shine band is a stepped `transform` animation on a gradient layer, masked by progressively denser dither tiles. The browser runs it off the main thread, so it keeps moving while the page is busy loading.
- **Continuous across a page:** The dither grid and band phase are anchored to page coordinates, measured once on mount in a single batched read.
- **Reduced motion:** When the user prefers reduced motion, the band stays still.

### Trade-offs

Compared to `DitheredSkeleton`, the resting texture doesn't drift, the band edge is straight rather than rippled, and there's no `grain` option. Very large instances also allocate a wider compositor layer (element width plus 1100px) for each of the three shine levels.
