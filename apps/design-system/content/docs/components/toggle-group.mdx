## Segmented

A Supabase addition, not part of shadcn or Radix. A segmented control is a compact row of two to
four mutually exclusive options sharing one continuous track, for switching view state (Data or
Definition) or filtering a list (All, Active, Revoked). The choice takes effect immediately and is
never saved, so reach for a [Switch](../components/switch) or
[Radio Group](../components/radio-group) when the setting is persisted, and
[Tabs](../components/tabs) when the options swap whole panels of content. Items paint nothing
themselves; a single indicator slides between them, so the group always has exactly one thing
selected. Give a filter an explicit **All** segment rather than letting deselection stand for
"no filter".

### Segmented props

| Prop            | Values                                | Default     | Notes                                                                                                                                                                                                     |
| --------------- | ------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `variant`       | `'segmented'`                         | `'default'` | Opts into the segmented treatment: no gaps, no per-item borders, `cursor-pointer`, and an indicator that slides between segments and respects `prefers-reduced-motion`. The other variants are untouched. |
| `type`          | `'single'`                            |             | Only a single-select group gets the indicator. A `'multiple'` group falls back to items painting their own selected background.                                                                           |
| `allowDeselect` | `boolean`                             | `true`      | Radix clears the selection when you click the active item, emitting `''`. Set `false`, since a segmented control has no empty state.                                                                      |
| `tone`          | `'text' \| 'outline' \| 'primary'`    | `'text'`    | `text` is a flat `bg-accent` fill, `outline` adds a container border and a raised bordered indicator, `primary` fills the indicator with brand.                                                           |
| `size`          | `'tiny' \| 'sm' \| 'default' \| 'lg'` | `'default'` | `tiny` suits a dense toolbar or table footer. Segments hug their labels, so add `className="flex-1"` to each item, plus a width on the root, if you need them equal.                                      |
| `aria-label`    | `string`                              |             | Required. Describes what is being switched or filtered; the segments name the options, not the axis.                                                                                                      |

## Props

`ToggleGroup` forwards every prop to the underlying
[Radix Toggle Group](https://www.radix-ui.com/docs/primitives/components/toggle-group#api-reference),
and adds the following.

| Prop            | Type                                    | Default     | Description                                                               |
| --------------- | --------------------------------------- | ----------- | ------------------------------------------------------------------------- |
| `variant`       | `'default' \| 'outline' \| 'segmented'` | `'default'` | Styles the root and every item. Items inherit it through context.         |
| `size`          | `'tiny' \| 'sm' \| 'default' \| 'lg'`   | `'default'` | Item height and padding. Items inherit it through context.                |
| `allowDeselect` | `boolean`                               | `true`      | Whether clicking the active item in a `type="single"` group clears it.    |
| `tone`          | `'outline' \| 'text' \| 'primary'`      | `'text'`    | Button-flavored styling for a segmented group. Ignored by other variants. |

`variant` and `size` are the shadcn variant axes; `segmented` and `allowDeselect` are the Supabase
additions. `default` and `outline` are unchanged from shadcn.
